Documentación sobre las etiquetas HTML fundamentales utilizadas para estructurar el contenido, los textos y los elementos visuales de nuestro proyecto.

Diccionario de Etiquetas

Usos y Ejemplos

<h1> a <h6> y <p>
  • Uso apropiado: Los <h1> a <h6> estructuran los títulos por orden de importancia. El <p> se utiliza para definir bloques de texto.
  • Uso en el sitio: Se utilizó el h1 para el nombre principal en la página de perfil, h5 para habilidades, y p para las descripciones.

<a> e <img>
  • Uso apropiado: <a> crea botones o enlaces hacia otras páginas. <img> inserta recursos gráficos en la interfaz.
  • Uso en el sitio: Se utilizaron para los botones de navegación, el logo del equipo y las fotos de los perfiles.

Evidencia: Fragmento de código HTML.

Evidencia: Perfil del integrante.

<div> y <span>
  • Uso apropiado: <div> agrupa elementos en bloque. <span> da estilo en línea a textos o insignias.
  • Uso en el sitio: El div estructuró el bloque de proyectos. El span se usó principalmente para tags.

Evidencia: Fragmento de código HTML.

Evidencia: Habilidades del integrante.

<ul>, <ol> y <li>
  • Uso apropiado: <ul> define listas desordenadas, <ol> listas ordenadas, y <li> los ítems internos.
  • Uso en el sitio: Se usaron listas desordenadas para enumerar las fortalezas técnicas del equipo en la página de inicio.

Evidencia: Fragmento de código HTML.

Evidencia: Técnicas del equipo.

<table>, <form>, <label>, <input> y <button>
  • Uso apropiado: <table> presenta datos tabulares. Las etiquetas <form>, <label>, <input> y <button> sirven para capturar datos ingresados por el usuario.
  • Uso en el sitio: Se utilizó una tabla para armar un resumen de roles. Las etiquetas from, label, input y button se utilizaron para una prueba de interacción de contacto.
