Principales Comandos
de Docker.

Guía de referencia rápida con los comandos más utilizados para la gestión de imágenes y contenedores.

Comando / Sintaxis Descripción Ejemplo de Uso Resultado Esperado
docker --version Consultar la versión instalada. docker --version Muestra la versión actual de Docker instalada en el sistema.
docker run hello-world Ejecutar una imagen de prueba. docker run hello-world Descarga la imagen hello-world (si no existe) y muestra un mensaje de éxito.
docker images Listar imágenes locales. docker images Muestra una tabla con todas las imágenes descargadas, su etiqueta y tamaño.
docker ps Mostrar contenedores en ejecución. docker ps Lista los contenedores activos actualmente con sus IDs y puertos mapeados.
docker ps -a Mostrar todos los contenedores. docker ps -a Muestra el historial completo de contenedores, incluyendo los que están detenidos.
docker build -t [nombre] . Construir una imagen desde un Dockerfile. docker build -t mi-web . Lee el Dockerfile del directorio actual y crea una imagen llamada "mi-web".
docker run [opciones] [imagen] Crear y ejecutar un contenedor. docker run -d -p 80:80 nginx Inicia un nuevo contenedor en segundo plano mapeando el puerto 80.
docker stop [contenedor] Detener un contenedor. docker stop mi-web-container Apaga de forma segura el contenedor especificado.
docker start [contenedor] Iniciar un contenedor detenido. docker start mi-web-container Vuelve a encender un contenedor que había sido apagado.
docker rm [contenedor] Eliminar un contenedor. docker rm mi-web-container Borra el contenedor del sistema (debe estar detenido primero).
docker rmi [imagen] Eliminar una imagen. docker rmi mi-web-html Borra la imagen almacenada localmente para liberar espacio.
docker logs [contenedor] Consultar registros de un contenedor. docker logs mi-web-container Muestra la salida de la consola y errores del contenedor para diagnóstico.
docker exec -it [contenedor] bash Ejecutar comandos dentro de un contenedor. docker exec -it mi-web bash Abre una terminal interactiva dentro del contenedor en ejecución.
