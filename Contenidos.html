Evidencia de la investigación técnica realizada por el equipo, con ejemplos y documentación detallada.

Docker

Introducción: Plataforma que permite empaquetar aplicaciones y sus dependencias en contenedores aislados, asegurando que el proyecto funcione igual en cualquier computadora.

// Ejemplo de configuración (Dockerfile)
FROM nginx:alpine
COPY . /usr/share/nginx/html/
Ir a la investigación de Docker →

Comandos Docker

Introducción: Instrucciones de línea de comandos (CLI) utilizadas para construir imágenes, levantar servidores y administrar el ciclo de vida de los contenedores.

// Ejemplo de ejecución
docker build -t mi-web .
docker run -d -p 8080:80 mi-web

CSS (Hojas de Estilo en Cascada)

Introducción: Lenguaje de diseño utilizado para definir la presentación, colores, tipografías y el aspecto visual general de nuestras páginas web.

/* Ejemplo de regla CSS */
.bg-dark {
  background-color: #1a1a1a;
  color: white;
}
Ir a la investigación de CSS →

Bootstrap

Introducción: Framework de CSS que facilita la creación de sitios web responsivos (adaptables a móviles) mediante un sistema de grillas y componentes pre-estilizados.

<!-- Ejemplo de uso de clases Bootstrap -->
<div class="container d-flex justify-content-center">
  <button class="btn btn-primary">Clic aquí</button>
</div>
Ir a la investigación de Bootstrap →

Etiquetas semánticas de HTML

Introducción: Etiquetas que aportan significado estructural al contenido (para qué sirve cada parte), mejorando la accesibilidad y el posicionamiento en buscadores (SEO).

<!-- Ejemplo de semántica -->
<header>Encabezado del sitio</header>
<main>Contenido principal</main>
<footer>Pie de página</footer>
